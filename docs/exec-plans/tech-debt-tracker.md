# 技术债务追踪

| 优先级 | 债务 | 影响 | 建议处理 |
| --- | --- | --- | --- |
| P0 | AI 发送按钮未接线 | 用户无法完成 AI 任务闭环 | 接入服务端 API、流式状态和错误恢复 |
| P0 | 没有真实数据层和认证 | 目前只能展示静态原型 | 明确身份、租户、权限和 API 契约后再接入 |
| P1 | 业务页面都是 `ContentPlaceholder` | 导航入口不能承载真实工作 | 按产品规格拆分领域页面与数据查询 |
| P1 | 没有自动化测试 | 路由、键盘和响应式回归不可见 | 引入组件/路由测试及关键流程 E2E |
| P2 | 搜索仅过滤导航标签 | 与搜索占位文案不一致 | 设计统一搜索索引、权限过滤和结果分组 |
| P2 | `DESIGN.MD` 为大型外部资料副本 | 维护成本高，项目规则不够集中 | 保留来源资料，在 `docs/DESIGN.md` 维护项目摘要 |
