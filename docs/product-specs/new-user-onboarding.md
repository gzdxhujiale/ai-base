# 新用户引导

## 目标

让首次进入企业工作台的用户在短时间内理解：当前企业、主要导航、全局搜索和企业 AI 的作用。

## 目标流程

1. 首次进入时确认当前企业和个人身份。
2. 介绍工作台、任务中心、应用中心和经营信息入口。
3. 引导用户使用 `⌘/Ctrl + K` 搜索。
4. 引导用户打开“问企业 AI”，展示一个安全且可执行的示例问题。
5. 记录完成状态，允许用户稍后从帮助入口重新查看。

## 当前实现

当前代码没有 onboarding 状态、引导弹层、认证或持久化；企业下拉、用户菜单和 AI 抽屉中的内容均为静态展示或占位交互。

## 验收标准

- 新用户可以跳过引导且不会阻塞工作台。
- 每一步都能通过可见控件完成或返回。
- 引导不泄露企业数据，不在客户端硬编码真实成员或密钥。
- 桌面和移动视口均能完成核心步骤。
