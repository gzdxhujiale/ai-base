# 工作台交互模型

## 入口

顶部栏提供品牌返回工作台、企业下拉、全局搜索、询问企业 AI 和用户菜单。桌面端显示完整搜索框，较窄视口只显示搜索图标和 AI 入口。

## 导航

当前导航项包括：我的工作台、任务中心、应用中心、知识库、经营地图、经营洞察、AI 升级、企业设置。前六项属于主工作区，企业设置以分割线隔开。所有角色均显示企业设置；侧边栏支持展开和收起，收起后使用 Tooltip 保留可发现性。

## 知识空间与角色视图

用户菜单可切换员工、管理者和经营者预置视图。切换即时更新导航与可操作项，且不表示真实登录或授权。知识库页在企业空间与个人空间间切换；企业空间按当前视图的演示授权过滤内容。企业设置对员工展示企业信息与回收站，对管理者增加获授权知识库的管理入口，对经营者增加 RBAC 权限管理。

知识空间的文档表格将分类和知识库编辑器放在对应列。操作列使用眼睛图标进入详情页；详情页通过面包屑和返回按钮回到原文档列表。

## 命令搜索

`⌘ K` 或 `Ctrl K` 打开命令 Modal；输入内容按中文标签过滤，最多展示 5 个导航结果。当前不搜索真实任务、应用或成员。路由跳转后 Modal 关闭。

## 企业 AI

AI 抽屉宽度为 440px，包含空状态、三个建议问题和多行输入框。当前点击建议只会填充输入框，发送按钮仅有禁用态判断，未发送请求，也未展示会话消息。

## 待补足的状态

真实产品需要补齐加载、无结果、提交中、提交失败、权限不足、网络恢复和移动端导航状态，并为键盘操作提供可访问的焦点顺序。
