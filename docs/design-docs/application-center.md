# 应用中心

## 当前原型行为

“应用中心”是工作台内的静态前端原型页面。它展示四项带有“演示统计数据”说明的指标，并提供空间维度与业务维度两个可叠加的筛选器。

- 空间筛选：全部、个人空间、公共空间、研发中心、客服中心。
- 业务筛选：全部、淘宝、快手、抖音、拼多多、人事、财务。
- 卡片内容是本地占位数据，不代表已安装应用、运行实例或真实业务结果。

## 创建应用

“创建应用”打开模态弹窗，包含“使用应用模板”和“创建空白应用”两种方式。空白应用必须填写名称；创建成功后只追加到当前浏览器会话中的本地列表，刷新页面会丢失。该交互不创建服务端资源，也不触发 AI、自动化或数据处理。

## 加入工作台

应用详情页提供“加入工作台”按钮。加入后，按钮改为“从工作台移除”，应用会追加到“我的工作台”的“常用工作入口”；移除后入口即时消失。点击入口会再次打开应用详情。加入状态只保存在当前浏览器会话的内存 UI 状态中，刷新后会丢失。
