# 核心信念

## 工作台首先要降低寻找成本

用户进入系统通常是为了找到任务、应用、成员或经营信息。导航、搜索和页面层级应先回答“我在哪里、还能做什么、下一步是什么”，再展示装饰性信息。

## AI 是工作流入口，不是独立展厅

企业 AI 应出现在用户已有工作流旁边，并能引用当前企业上下文、返回可执行结果。当前抽屉只是入口原型；在接入后端前，不应宣称已具备企业知识问答能力。

## 状态要可见且可恢复

搜索、抽屉、路由切换、异步请求和错误都需要有明确反馈。破坏性操作需要确认；异步失败应给出原因和下一步，而不是只显示技术错误码。

## 一致性胜过局部炫技

颜色、圆角、间距、按钮层级和文案遵循 Arco Design 与项目 token。新的模式只有在能显著改善任务效率时才引入，并同步补充本目录文档。

## 原型状态必须诚实

静态占位内容、未接线按钮和未来能力必须显式标注。产品规格描述目标体验，架构和质量文档描述实际实现，两者不混写。
