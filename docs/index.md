# AI Base 知识库

本目录是项目版本化知识与 VitePress 文档源。当前应用是企业工作台前端原型：已实现工作台壳、导航、命令搜索入口和 AI 抽屉，尚无服务端、认证、真实数据或 AI 服务。

## 从这里开始

- [架构总览](/architecture/)：系统形态、代码边界与当前运行路径。
- [前端工程模型](/FRONTEND)：组件、状态、路由与验证方式。
- [设计原则](/DESIGN)：稳定的视觉与交互不变量。
- [产品判断](/PRODUCT_SENSE)：需求存在空白时的取舍框架。
- [复杂工作计划协议](/PLANS)：何时以及如何维护 ExecPlan。
- [质量记分卡](/QUALITY_SCORE)：当前最重要的质量缺口。
- [Agent 治理](/agent/skill)：Skills 的使用边界与维护方式。

具体设计决策位于 [设计文档](/design-docs/)，具体产品行为位于 [产品规格](/product-specs/)，当前技术债务计划位于 [执行计划](/exec-plans/tech-debt-tracker)。
