# 计划与路线图

## 近期优先级

1. 明确认证、企业租户和权限模型。
2. 为任务、应用、成员和经营数据定义 API 契约。
3. 将导航占位页拆成真实领域页面，并接入 TanStack Query。
4. 接入企业 AI 服务，支持会话、流式响应、错误处理和审计。
5. 建立组件测试、路由测试和关键流程 E2E。

## 计划规则

执行计划放在 `docs/exec-plans/active/`，完成后移到 `completed/`。每个计划需要包含目标、非目标、依赖、分步实施、验收标准、观测指标、风险和回滚方案。

## 当前非目标

在没有明确后端契约前，不实现真实企业数据同步、数据库、用户认证或 AI 请求代理；不把静态演示数据伪装成真实数据。
