# AI Base 知识库

AI Base 是一个企业工作台前端原型。本知识库记录当前实现、产品意图、设计原则、工程约定和后续计划。

## 从这里开始

- [架构总览](/architecture/)：了解应用启动、路由、状态和模块边界。
- [前端工程约定](/FRONTEND)：了解目录、样式、路由和检查命令。
- [产品规格](/product-specs/)：了解工作台的产品范围与新用户引导目标。
- [设计文档](/design-docs/)：了解核心信念和工作台交互模型。
- [路线图与计划](/PLANS)：了解当前优先级、非目标和执行计划规则。

## 当前实现边界

当前仓库提供工作台壳、导航、命令搜索入口和企业 AI 抽屉原型。暂无认证、后端 API、数据库、持久化或真实 AI 服务；文档中的规划内容会明确标注为计划或待实现。

## 本地运行

```bash
pnpm docs:dev
```

构建静态文档站：

```bash
pnpm docs:build
```

预览构建结果：

```bash
pnpm docs:preview
```
