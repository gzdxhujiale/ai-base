# 安全

## 当前边界

仓库没有认证、授权、服务端 API、数据库或密钥配置。当前 UI 中的企业名称、用户名称、菜单项和 AI 建议均为演示内容。

## 接入后必须明确

- 认证方式、会话过期、登出和跨标签页状态。
- 企业租户隔离、成员角色、页面与数据级权限。
- AI 请求的上下文授权：模型只能看到当前用户有权访问的数据。
- 敏感信息脱敏、提示词注入防护、输出审查和审计保留策略。
- API 的 CSRF、CORS、速率限制、输入校验和错误信息边界。
- 生产环境 CSP、依赖漏洞扫描、日志脱敏和密钥注入方式。

## 前端规则

不要把密钥、令牌或真实企业数据硬编码进 `src/` 或静态资源。所有来自用户、URL、远端服务和 AI 的内容都要按不可信输入处理；渲染富文本或 Markdown 时必须使用安全白名单和转义策略。
